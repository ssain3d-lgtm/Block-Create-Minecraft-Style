# Windows · RTX 5090 직접 점검 방법

> 이 문서의 항목은 **사용자 PC에서 직접 해야 하는 점검**입니다. 개발 환경(클라우드, GPU 없음)에서는
> 아래 1·2번의 자동 검사만 실행했고, 3번(GPU 성능)은 실행하지 못했습니다.

## 0. 준비 (한 번만)

1. [Node.js](https://nodejs.org) 20 이상 설치 (LTS 권장)
2. 이 레포를 받은 폴더에서 명령 프롬프트(cmd)를 엽니다.
3. `npm install`
4. 브라우저 자동 검사를 쓰려면: `npx playwright install chromium`

## 1. 자동 검사 (약 5~10분)

| 명령 | 확인하는 것 | 통과 기준 |
|---|---|---|
| `npm run typecheck` | 타입 오류 | 출력 없음 |
| `npm test` | 엔진·보안·저장·트랜잭션·동기화·다중 셀 부품 단위 테스트 | `Tests  N passed` |
| `npm run check:studio` | 실제 브라우저에서 블록 추가·삭제·되돌리기·자동 저장·언어 전환 | 모든 줄이 `ok` |
| `npm run check:ai` | HTTP API·실시간 연동(탭 2개+AI 동시 편집, 끊김 후 재접속)·스크린샷·MCP | `all AI-side checks passed` |
| `npm run build` | 배포용 빌드 | `built in …` |

Windows에서는 위 검사가 **실제 GPU**로 브라우저를 띄웁니다(헤드리스 모드여도 GPU 사용).

## 2. 손으로 하는 점검 (약 10분)

1. `run.bat` 실행 → 브라우저에 http://127.0.0.1:7878 이 열림, 오른쪽 아래 상태바에 `● 서버 연결`
2. **AI 명령 → 예제 불러오기 → A. 에펠탑** → 1~2초 안에 탑이 보이는지
3. 블록 편집 **추가**로 블록을 몇 개 놓고 `run.bat` 창을 닫음(Ctrl+C) → 다시 `run.bat` → 놓은 블록이 남아 있는지 (종료 직전 저장)
4. 브라우저 탭을 **2개** 열어 한쪽에서 블록을 놓으면 다른 쪽에도 바로 보이는지
5. 한 탭에서 **Ctrl+Z** → 두 탭 모두 되돌아가는지 (되돌리기는 서버 공용 기록)
6. `projects\current.vox.json`을 메모장으로 열어 앞부분만 남기고 저장(일부러 손상) → `run.bat` 재시작 → "recovered from current.vox.json.bak1" 메시지와 함께 이전 상태로 열리는지
8. 오른쪽 위 **EN / 한국어** 버튼으로 화면 언어가 바뀌고, 새로고침 후에도 유지되는지
7. 다른 사이트에서 접근이 막히는지: 브라우저 주소창에 `http://127.0.0.1:7878/api/state` → `NO_TOKEN`(401)이 나오면 정상

## 3. RTX 5090 성능 측정 (약 3분)

1. `bench.bat` 실행 → 브라우저가 `?bench=1`로 열리고, 창을 앞에 둔 채 기다립니다.
2. 결과 표가 나오면 **결과 JSON 저장**을 눌러 파일을 받습니다.
3. 받은 파일을 레포의 `bench/results/`에 넣고 커밋하거나, 대화창에 첨부해 주세요.

표의 의미:

| 열 | 의미 | 참고 목표(설계안 9.3) |
|---|---|---|
| 메시ms | 블록 → 화면용 모양 변환 시간 | — |
| 첫 프레임ms | 처음 그려지기까지 | 3초 이내 |
| 평균 FPS / 1% low | 10초 회전 중 평균 / 가장 느린 1% 구간 | 60 근처 |
| draw | 프레임당 그리기 호출 수 | 낮을수록 좋음 |
| 편집1000ms | 블록 1000개 편집이 화면에 반영되는 시간 | 100ms 이내 |

> 노트북 등 GPU가 두 개인 PC에서는 Windows 설정 → 디스플레이 → 그래픽에서 브라우저를 "고성능"(RTX)으로 지정한 뒤 측정하세요.

## 4. MCP 점검 (로컬 LLM)

1. `run.bat`을 켜 둡니다.
2. LM Studio / Claude Desktop / Qwen Code의 MCP 설정에 README의 예시를 넣습니다.
3. AI에게: *"voxel-studio의 get_guide를 읽고 작은 집을 지어 줘. 다 지으면 inspect와 render_views로 확인해."*
4. 열린 스튜디오에 집이 실시간으로 지어지면 정상입니다.
